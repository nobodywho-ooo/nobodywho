## What is NobodyWho?

NobodyWho is a lightweight, open-source inference engine for running open-weight language models inside your software. It provides a simple API that works offline and does not need additional infrastructure.

NobodyWho supports tool calling, structured output, token streaming, and embeddings. [llama.cpp](https://github.com/ggml-org/llama.cpp) runs the models behind the API.

You can use NobodyWho from Kotlin, Python, Swift, React Native, Flutter, and Godot. You do not need a model server, an API key, or Docker.
